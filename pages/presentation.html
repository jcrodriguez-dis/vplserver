About VPL

Presentation

A practical environment for programming education

Virtual Programming Lab is a Moodle activity for creating programming assignments. Students can edit source files, compile or run their work, and submit it from one place.

Teachers can define execution settings, tests, and evaluation criteria that fit the course. The result is a repeatable workflow that supports both formative practice and graded assignments.

Open and adaptable

VPL is free and open-source. It is designed to work with many programming languages and can be adapted to the needs of an institution or course.
